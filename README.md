# Class widget 2 时间组件

#### 介绍
原有class widget 2 可编辑的内容较少，使用Deepseek V4 Flash开发插件，给时钟显示增加更多功能

#### 安装教程

插件文件导入：
1.  下载 com.time.model.cwplugin 文件
2.  打开 class widget 2，在插件页导入文件
3.  启用 “时间组件”
3.  在小组件编辑界面添加组件即可

插件在线下载：
1.  打开插件广场
2.  搜索时间组件
3.  下载并启用

#### 使用说明

对比原版，增加了一些功能
1.  可以自由选择日期与星期的展示方式
2.  可以选择是否开启动画，避免课堂干扰
3.  自由选择组件展示内容

## SDK 版本

本插件已升级适配 Class Widgets 2 SDK **0.6.0**（`cwplugin.json` 中 `api_version: ~=0.6.0`），
使用官方 `ClassWidgets.SDK` 接口（`CW2Plugin` / `PluginAPI`：`api.widgets` / `api.ui` / `api.notification` / `api.schedule` / `api.config` / `api.runtime` 等）。
